# Security policy

The skills here are prompt files plus self-contained HTML templates that run in the browser. They make no network requests and handle no credentials, so the realistic risks are script injection through a generated card and a compromised dependency in the test tooling.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/amir-afianian/pyamir.io/security/advisories/new), not in a public issue. Include the skill, its version, and the smallest prompt or file that shows the problem.

Fixes ship as a patch release of the affected skill, and the advisory credits you unless you ask otherwise.

## Supported versions

Only the latest release of each skill gets security fixes.
